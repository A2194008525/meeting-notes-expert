# 会议纪要专家（meeting-notes-expert）

一个面向 AI Agent 的**会议纪要整理技能**：把会议录音转写稿、手写笔记、讨论记录、聊天记录等原始材料，整理为完整、清晰、可直接归档执行的结构化会议纪要。

> 当前版本：v1.1 ｜ 适用平台：ZCode / Claude Code 及其他支持 Agent Skills（SKILL.md）规范的助手 ｜ License: [MIT](LICENSE)

---

## ✨ 功能特性

- **五段式标准结构**：会议基本信息 → 会议内容 → 核心要点 → 会议总结 → 待办事项，一次成文、格式统一。
- **一个议题只说一次**：讨论细节在「会议内容」闭环，一句话提炼归「核心要点」，成果决策收束到「会议总结」，同一事实不在多个章节重复展开。
- **决策可审计**：关键决策逐条标注状态（已定 / 待定 / 待确认），材料可溯源的附简短依据，不可溯源的如实标「待确认」，绝不臆造引用。
- **待办可直接执行**：七列表格（序号 / 待办事项 / 责任人 / 完成时间 / 优先级 / 验收标准 / 备注），统一按优先级高→低、同级时间早→晚排序，缺失信息标「待定」不推断。
- **公文级排版规范**：内置 A4 公文格式（宋体 / 仿宋分级字号、固定 28 磅行距、Word 内置标题样式可生成导航目录），适合政务与体制内场景直接交付。
- **忠实记录，绝不脑补**：一切陈述可追溯至原始记录；材料未明确的信息一律标注「待确认」，不主观臆断、不遗漏、不添加个人情感。

## 📋 输出模板

纪要固定包含以下五个部分：

| 部分 | 呈现方式 | 说明 |
| --- | --- | --- |
| 一、会议基本信息 | 逐行文字罗列（严禁表格） | 会议主题 / 时间 / 地点 / 参会人员 / 记录人等，未提供的标「待确认」 |
| 二、会议内容 | 按议题分节 | 议题名称 + 主要讨论内容 + 关键发言要点，忠实原始记录 |
| 三、核心要点 | 逐条一句话 | 关键结论与重要信息，只提炼不展开，不与「会议内容」重复 |
| 四、会议总结 | 成果与决策收束 | 决策标注状态与依据；争议未决事项单独列出并标注状态 |
| 五、待办事项 | 规范表格 | 含验收标准列，便于按责任人、完成时间、验收口径跟踪分摊 |

## 🚀 安装

将本仓库的 `SKILL.md` 放入你的 Agent 技能目录即可：

| 平台 | 技能目录 |
| --- | --- |
| ZCode | `~/.zcode/skills/meeting-notes-expert/SKILL.md` |
| Claude Code | `~/.claude/skills/meeting-notes-expert/SKILL.md` |

> 也可以整目录克隆：`git clone https://github.com/A2194008525/meeting-notes-expert.git`，再把 `meeting-notes-expert` 文件夹拷入对应技能目录。

## 💬 使用方法

技能支持指令触发与自然语言触发，安装后对 Agent 说：

```text
帮我整理一下会议纪要，材料在 meeting-notes.md
把这段会议记录提炼成正式纪要，重点提取待办事项
整理今天的周会纪要，录音在 audio/20260918周会.m4a
```

### 音频输入（可选）

如果提供的是**会议录音**（`.wav / .m4a / .mp3 / .flac / .aac` 等），本技能会先调用 `funasr-transcribe` 转写技能完成转写（多人会议自动区分说话人），再以转写稿为会议记录进入提炼流程。纯文本材料无需任何额外依赖。

> 没安装转写技能时，请先自行将录音转写为文本，再交给本技能整理。
